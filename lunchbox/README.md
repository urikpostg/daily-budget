# Ланчбокс

Невеликий застосунок, щоб не тримати в голові, які страви треба приготувати вдома
й принести дитині в школу — коли шкільне меню не підходить через алергію.

**Як користуватись.** Тиждень показано списком днів, у кожному дні п’ять чіпів:
сніданок, перекус, обід, підвечірок, вечеря. Дотик до чіпа позначає, що цього дня
цю страву готуєте самі. Угорі завжди видно, що треба на **сьогодні** й на **завтра**
(а якщо найближчі два дні вільні — коли готувати наступного разу).

- гортання вліво/вправо або стрілки — інші тижні;
- «＋ нотатка» — що саме приготувати чи не забути;
- **Минулий тиждень** — скопіювати позначки з попереднього тижня;
- **Щотижневий розклад** (у налаштуваннях) — постійні дні, якими можна заповнити
  порожній тиждень одним дотиком;
- **Поділитися** — текстовий список тижня, щоб надіслати в месенджер.

У вихідні застосунок одразу відкриває наступний навчальний тиждень.

## Технічно

Одна сторінка без збірки й без сервера: `index.html` (розмітка, стилі, логіка),
`sw.js` — офлайн-кеш, `manifest.json` + іконки — встановлення на домашній екран
(Android і iOS: «Поділитися» → «На початковий екран»).

Дані лежать у `localStorage` цього пристрою, ключ `lunchbox.v1`; синхронізації між
пристроями немає. У налаштуваннях є «Резервна копія» / «Відновити з копії» — це
JSON у буфері обміну.
